# 프로방스 가락동 노래방 - 디자인 아이디어

## 선택된 디자인: 우아한 모던 럭셔리 (Elegant Modern Luxury)

### 디자인 철학
프로방스라는 이름에서 영감을 받아, 남프랑스의 라벤더 밭과 고급스러운 유럽 감성을 현대적으로 재해석한 디자인입니다. 고급 노래방 경험을 제공하는 프리미엄 브랜드 이미지를 강조하며, 세련되고 차분하면서도 따뜻한 분위기를 연출합니다.

### 핵심 원칙
1. **우아한 미니멀리즘**: 불필요한 요소를 제거하고 핵심 정보에 집중
2. **따뜻한 럭셔리**: 차가운 네온이 아닌 따뜻한 골드/크림 톤의 프리미엄 느낌
3. **공간감과 호흡**: 넉넉한 여백으로 고급스러운 분위기 연출
4. **감정적 연결**: 사용자의 특별한 경험을 상상하게 하는 스토리텔링

### 색상 철학
- **주 배경**: 진한 크림색/오프화이트 (따뜻함) + 어두운 슬레이트 (고급스러움)
- **강조색**: 골드/샴페인 (프리미엄 느낌) + 부드러운 라벤더 (프로방스 이미지)
- **텍스트**: 진한 갈색/검정 (명확성) + 화이트 (대비)
- **감정**: 고급스럽고 안정적이며 따뜻한 느낌

### 레이아웃 패러다임
- **비대칭 구성**: 왼쪽에 텍스트, 오른쪽에 이미지 배치 (또는 그 반대)
- **플로팅 요소**: 이미지와 텍스트가 겹치는 레이어 효과
- **섹션 분리**: 미묘한 배경색 변화와 여백으로 섹션 구분
- **수직 리듬**: 일관된 간격으로 시각적 안정감 제공

### 시그니처 요소
1. **골드 라인 구분선**: 섹션 사이에 얇은 골드 선으로 우아함 강조
2. **라벤더 액센트 카드**: 특징 소개 카드에 부드러운 라벤더 배경
3. **타이포그래피 강조**: 세리프 폰트의 우아한 헤드라인 + 산세리프 바디

### 인터랙션 철학
- **부드러운 전환**: 모든 호버 효과는 부드럽고 우아하게 (200-300ms)
- **미묘한 깊이**: 버튼 클릭 시 살짝 내려가는 느낌 (depth)
- **스크롤 애니메이션**: 요소들이 부드럽게 페이드인/슬라이드인
- **CTA 강조**: 전화 예약 버튼은 눈에 띄지만 과하지 않게

### 애니메이션
- **페이드인**: 스크롤 시 요소가 부드럽게 나타남 (opacity + slight translate)
- **호버 효과**: 버튼/카드에 마우스 올릴 때 색상 변화 + 그림자 강화
- **스케일 애니메이션**: 이미지 호버 시 1.02배 확대 (미묘함)
- **스로틀링**: 과도한 애니메이션 피하고 의도적인 순간에만 사용

### 타이포그래피 시스템
- **헤드라인**: Playfair Display (세리프, 우아함) - 큰 사이즈 (48px+)
- **서브헤드라인**: Lora (세리프, 가독성) - 중간 사이즈 (32px)
- **바디 텍스트**: Inter (산세리프, 현대적) - 16-18px
- **강조 텍스트**: Lora 이탤릭 또는 Inter 600 weight
- **계층 구조**: 명확한 크기 차이로 정보 우선순위 표현

## 대안 아이디어 (미선택)

### 아이디어 2: 현대 미니멀 (Modern Minimal) - 확률 0.08
모던하고 깔끔한 디자인으로 최신 감각을 강조. 검정/흰색 + 강한 원색 액센트. 기하학적 도형과 타이포그래피 중심.

### 아이디어 3: 따뜻한 비스트로 (Warm Bistro) - 확률 0.07
카페/와인바 감성의 따뜻한 톤. 베이지/갈색 + 와인레드. 손그림 요소와 빈티지 느낌.
