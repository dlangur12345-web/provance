# SEO 최적화 가이드 - 프로방스 가락동 노래방

## 구현된 SEO 최적화 사항

### 1. 메타 태그 최적화
- **Title Tag**: 55자 이내, 주요 키워드 포함
- **Meta Description**: 160자 이내, 클릭 유도 문구 포함
- **Keywords**: 관련 검색어 8개 포함
- **Canonical URL**: 중복 콘텐츠 방지
- **Robots Meta**: 크롤링 허용 설정

### 2. Open Graph (OG) 태그
- 소셜 미디어 공유 시 최적화된 미리보기 제공
- og:title, og:description, og:image, og:type 설정
- Facebook, LinkedIn 등에서 올바른 형식으로 표시

### 3. Twitter 카드
- Twitter 공유 시 최적화된 형식 제공
- summary_large_image 형식으로 이미지 강조

### 4. 구조화된 데이터 (Schema.org)
#### LocalBusiness Schema
- 비즈니스 정보 (이름, 주소, 전화번호)
- 운영 시간 (24시간 운영)
- 고객 평가 (4.9점)
- 가격대 정보

#### BreadcrumbList Schema
- 페이지 계층 구조 표시
- 검색 결과에서 경로 표시

### 5. 성능 최적화
- **이미지 최적화**: WebP 형식 사용, 반응형 이미지
- **폰트 최적화**: Google Fonts 프리로드
- **CSS 최적화**: Tailwind CSS 사용으로 불필요한 스타일 제거
- **접근성**: prefers-reduced-motion 지원

### 6. 시맨틱 HTML
- 적절한 heading 태그 계층 구조 (h1, h2, h3)
- section, article, footer 등 시맨틱 요소 사용
- aria-label로 섹션 접근성 강화
- role="contentinfo" 등 ARIA 역할 지정

### 7. 모바일 최적화
- 반응형 디자인 (모바일 우선)
- 모바일 플로팅 버튼으로 전화 예약 유도
- 뷰포트 메타 태그 설정

### 8. 사이트 설정 파일
- **robots.txt**: 크롤러 지침 제공
- **manifest.json**: PWA 설정, 앱 메타데이터
- **favicon.ico**: 브라우저 탭 아이콘

## 다음 단계

### 1. 구글 서치 콘솔 등록
```
1. Google Search Console 방문 (search.google.com/search-console)
2. 도메인 추가
3. 소유권 확인 (HTML 파일 업로드 또는 메타 태그)
4. 사이트맵 제출
```

### 2. 구글 비즈니스 프로필 등록
```
1. Google Business Profile 방문
2. 비즈니스 정보 입력 (주소, 전화번호, 운영 시간)
3. 사진 및 리뷰 추가
4. 고객 응답 관리
```

### 3. 사이트맵 생성 및 제출
```
- 현재: 동적 사이트맵 필요
- 추천: 정적 XML 사이트맵 생성 후 robots.txt에 추가
```

### 4. 로컬 SEO 최적화
```
- 네이버 플레이스 등록
- 카카오맵 등록
- 지역 관련 키워드 추가
```

### 5. 콘텐츠 마케팅
```
- 블로그 포스트 작성 (노래방 팁, 추천곡 등)
- FAQ 섹션 추가
- 고객 리뷰 수집 및 표시
```
